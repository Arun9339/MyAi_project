# MyAI

MyAI is an AI-powered application built for interacting with AI models through a modern web interface.

## Features

- AI chat interface
- Multiple AI model support
- Conversation management
- Modern and responsive UI
- Customizable AI interactions

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- AI APIs
